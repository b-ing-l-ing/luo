# 梗图库

把图片放在这个目录，**文件名就是标签**：

- `无语.png`
- `笑死.jpg`
- `鼓掌.gif`
- `晚安.webp`

支持 png / jpg / jpeg / gif / webp。单张建议小于 1MB，QQ 发送更稳。

模型会在合适时调用 `send_meme` 发出去；也可以手动测试：

```text
/meme 无语
```

## 存别人发的图

给洛发一张图，然后说：

```text
存这张图
/save 无语
```

- 不带标签：用时间戳命名，例如 `saved_20261028_193000.png`
- 带标签：文件名就是标签，例如 `无语.png`，以后可以直接 `/meme 无语` 发回来
- 只缓存最近 3 张图，且只在进程内；重启后需要重新发图
